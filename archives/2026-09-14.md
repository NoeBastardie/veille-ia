## Message publié

Salut à tous :wave:

Anthropic a rendu *Claude in Chrome* disponible sur tous les plans payants, et la CNIL vient de publier avec le Conseil de l'IA et du Numérique une note sur ce que ce type d'agent change pour les données personnelles — les deux sujets se répondent directement.

:robot_face: *Claude in Chrome* — l'extension qui fait agir Claude directement dans le navigateur (clic, saisie, navigation entre onglets) sans connecteur à coder, en autonomie validée par un classifieur de sécurité.
Pour un PM, c'est un moyen de prototyper une automatisation sur un outil interne sans API avant d'investir dans une vraie intégration.
• installer l'extension sur un plan payant et lui faire exécuter une tâche répétitive multi-outils qu'on fait encore à la main chaque semaine

:balance_scale: *Note CNIL x CIANum sur l'IA agentique* — analyse conjointe de ce que la délégation d'action à un agent change pour la protection des données : circulation entre services, mémoire persistante, responsabilité éclatée.
Pas encore traité ici alors que le sujet date de juillet : c'est la grille qu'un DPO appliquera à toute feature agentique qu'on cadre, mieux vaut l'anticiper.
• reprendre le cadrage d'une feature agentique en cours et vérifier qu'on peut dire qui est responsable de quoi et quelles données circulent entre quels services

:warning: À prendre avec des pincettes : Claude in Chrome tourne seulement sur Chrome desktop, pas sur le plan gratuit ni sur mobile ; la note CNIL est exploratoire, sans obligation ni sanction nouvelle à ce stade.

:point_right: Je teste Claude in Chrome cette semaine sur un cas de suivi multi-outils et je partage si l'autonomie tient sans supervision constante.
